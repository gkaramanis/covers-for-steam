# Covers for Steam

A macOS screensaver that shows the cover art from your Steam library, read
straight from Steam's local cache. Pick Wall (a grid of tiles) or Origami
(panels that fold in new covers) under Options.

Download the notarized `.saver` from
[Releases](https://github.com/gkaramanis/steam-screensaver/releases) and
double-click it, or build it with `./build.sh --install`. Then choose **Covers for Steam** in System Settings → Screen Saver.
